IllusionGameSelfAssociation - DDM-5 against the LNR

The paper’s model is a log-normal race (LNR, analysis/models/lnr.rds). This report sets the DDM-5 (analysis/models/ddm5.rds; ddm5 in analysis/server/models.R) against it, to decide whether the paper should switch to it: does it fit the data better, does it sample better, and does it tell the group story more clearly? Both models have the same fixed part (Group × a strength × difficulty surface per illusion on every parameter), the full participant surface on the drift, priors from IllusionGameComputational by the same rules, and the same 55,937 trials. Everything is computed here, for both fits, by the same code (analysis/server/marginals.R), except the LNR’s participant estimates, which are read from analysis/results/lnr_participants.csv (4_lnr_correlates.qmd). The DDM-5’s numbers are written to analysis/results/ddm5_*.csv. Render from the repo root (about 20 min; it needs cogmod ≥ 0.3.6):

quarto render analysis/5_ddm_vs_lnr.qmd

The answer is in the last section, “Summary: should the paper switch?”.

The two models side by side

Both are models of the choice and the response time together, with an outlier component (poutlier, with no Group term) for the responses neither process explains. They put the same questions into different parameters:

Question LNR DDM-5
Time outside the decision (encoding, motor) ndt ndt
How well the targets are told apart discriminability δ = ν₀ − ν₁, the correct accumulator’s advantage the drift towards the correct response, v = −mu (dec(Error) puts the error on the upper boundary)
How much evidence is gathered before responding none directly: the threshold is fixed at 1, and the overall speed (ν₀ + ν₁) / 2 stands in for (inverse) caution the boundary separation boundary
A response favoured before the evidence none (sigmabias = 0) the start point bias, as a share of the boundary from the correct one (> 0.5: closer to the error)
Trial-to-trial noise σ₀ and σ₁, the spread of each accumulator’s log-rate sigmadrift, the spread of the drift across trials
P(error) Φ(−δ / √(σ₀² + σ₁²)), closed form the probability of reaching the error boundary first, averaged over the trial-to-trial drift (quadrature, igsa_ddm_perror())
Illusion magnitude the strength slope of δ over its difficulty slope, at strength 0 and mid difficulty the same ratio on v

Every parameter of both models varies with strength and difficulty, as the LNR’s do in the paper.

Fit to the data

Predictive accuracy

Leave-one-trial-out cross-validation (PSIS-LOO) on about 1,000 posterior draws per model, spread evenly over the chains. The log-likelihood is the joint density of the response time and the choice, outlier component included, so the two models are on the same scale. Higher is better.

Code 
# Evenly spaced draws within each chain, so that loo can estimate the
# relative efficiency from the chains.
per_chain_ids <- function(m, total = 1000) {
  k <- ceiling(total / nchains(m))
  n_iter <- ndraws(m) / nchains(m)
  list(ids = unlist(lapply(seq_len(nchains(m)) - 1, function(c) c * n_iter + round(seq(1, n_iter, length.out = k)))),
       chain = rep(seq_len(nchains(m)), each = k))
}

# brms::log_lik() calls the family once per trial; cogmod's densities are
# vectorised, so this computes the same numbers (checked to equality on the
# first 300 trials) in blocks of draws.
loglik <- function(m, ids, chunk = 250) {
  pars <- igsa_pars(m)
  do.call(rbind, lapply(split(ids, ceiling(seq_along(ids) / chunk)), function(i) {
    p <- lapply(setNames(pars, pars), function(q) posterior_linpred(m, dpar = q, transform = TRUE, draw_ids = i))
    x <- rep(m$data$RT, each = length(i))
    r <- rep(m$data$Error, each = length(i))
    ll <- if (m$family$name == "cogmod_ddm") {
      cogmod::dcogmod_ddm(x, drift = p$mu, boundary = p$boundary, bias = p$bias, ndt = p$ndt, response = r,
                          sigmadrift = p$sigmadrift, poutlier = p$poutlier, log = TRUE)
    } else {
      cogmod::dcogmod_lnr(x, nuzero = p$mu, nuone = p$nuone, sigmazero = p$sigmazero, sigmaone = p$sigmaone,
                          ndt = p$ndt, response = r, poutlier = p$poutlier, log = TRUE)
    }
    matrix(ll, nrow = length(i))
  }))
}

Posterior predictive checks

One hundred evenly spaced posterior draws per model simulate a choice and a response time for every trial, with the participant effects in, as in 3_lnr_groups.qmd. The simulated trials are summarised the way the observed ones are: the error rate and the median response time per pair of neighbouring strengths (the design is a checkerboard across blocks; see 3_lnr_groups.qmd), and the quantiles of correct and of error response times in three bands of strength (facilitating, strength ≤ −0.6; none, |strength| ≤ 0.3; conflicting, strength ≥ 0.6).

# posterior_predict() calls the family once per trial; cogmod's methods also
# take a vector of trials and return their draws stacked, trial by trial
# (cogmod's ?rcogmod_ddm, "Predicting many observations at once").
simulate <- function(m, ids) {
  prep <- brms::prepare_predictions(m, draw_ids = ids)
  for (dp in names(prep$dpars)) prep$dpars[[dp]] <- brms::get_dpar(prep, dp)
  fun <- if (m$family$name == "cogmod_ddm") cogmod::posterior_predict_cogmod_ddm else cogmod::posterior_predict_cogmod_lnr
  pp <- do.call(rbind, lapply(split(seq_len(prep$nobs), ceiling(seq_len(prep$nobs) / 50)), fun, prep = prep))
  n <- length(ids)
  stopifnot(nrow(pp) == n * prep$nobs, all(pp[, 2] %in% c(0, 1)))
  list(rt = matrix(pp[, 1], nrow = n), error = matrix(pp[, 2], nrow = n))
}

The illusion effect on P(error)

The change in P(error) from strength 0 to 1 at mid difficulty, in percentage points, per group and as group differences. This is the population level, as in 3_lnr_groups.qmd and the paper: a participant whose every random effect is zero. Fit: the DDM-5 predicts the data better. Its cross-validated log predictive density is ahead by 787 (SE 83) with fewer effective parameters (p_loo 2069 against 2846), with the Pareto k caveat above. Its median response times are off by 18 ms on average against 27 for the LNR, with 70% of the observed medians inside its 95% band against 51%. The error rates are close in both (off by 1.5 and 1.7 points). The shape of the distributions is better in places, not everywhere. With no illusion, its distributions are more peaked than the LNR’s, closer to the observed ones (the LNR’s main misfit), though still short of the observed peak in places. The slow half of the correct response times is closer (70th and 90th percentiles off by 41 and 110 ms, against 48 and 139). The slow tail of the errors is not (90th percentile off by 226 ms, against 200).

Sampling: much better. It has 0 divergent transitions (LNR: 28), a max Rhat of 1.015 against 1.044 on the population coefficients and of 1.024 against 1.268 on the participant ones, a minimum bulk ESS per draw of 0.080 against 0.017, and shards of 4–5 h against 7–32 h. None of the LNR’s caveats on convergence would be needed.

The group story: mostly the same, with the slowness in a parameter with a standard name. Averaged over the design and the illusions (median and 95% interval):

  • Caution. Users have a wider boundary: Past − Never 0.50 [0.22, 0.77], Recent − Never 0.48 [0.20, 0.74]. This is the LNR’s slower accumulators under another name: participants’ LNR speed and DDM-5 boundary correlate at ρ = -0.97.
  • Non-decision time. The LNR’s 49 [22, 77] and 41 [14, 67] ms become 19 [-4, 43] and 17 [-5, 40] ms. In the crude participant-level check, age accounts for all of it (age-adjusted: -6 [-27, 14] and -11 [-31, 9] ms). The paper’s longer non-decision time in users, and its age caveat, would mostly go.
  • Errors. Both models give users fewer errors: Recent − Never -4.2 [-7.3, -0.9] points (LNR) and -4.6 [-6.1, -3.1] (DDM-5).
  • Discriminability. In the DDM-5, Recent users are ahead of Past users (Recent − Past 0.51 [0.19, 0.83], pd 0.999), which the LNR does not show (0.26 [-0.18, 0.68]). That is the one place where “Past and Recent barely differ” would no longer hold.
  • Illusion magnitude. The same direction, larger and clearer: 6 of the six user − Never contrasts have pd ≥ 0.975 in the DDM-5, against 2 in the LNR. Relative to Never, the magnitude is 14–32% smaller in Past users and 13–36% in Recent users (LNR: 12–16% and 7–21%), most on the Ebbinghaus. Recent − Past is nothing in either model. Participants’ magnitudes agree between the models (ρ = 0.86), and age does not move the group differences in either.
  • Where the smaller magnitude comes from. In both models, users’ precision term is steeper. They differ on the other component. In the LNR, users’ illusion effect on discriminability is also larger than Never’s, by +8 to +22%. That is the paper’s steeper slope in users, which its Discussion has to reconcile with the smaller magnitude. In the DDM-5 it is about the same as Never’s (-11 to +10%). So the illusion costs users as much drift as anyone, and only the real difference has a larger effect on theirs. That story is simpler, and it needs no reconciling.

What speaks against it, as fitted. Its boundary and start point vary with illusion strength. Never’s boundary is 2.53 on the most facilitating trials and 1.77 on the most conflicting ones. Its start point is 0.73 and 0.52. The strengths are mixed at random within blocks, and a diffusion model reads both parameters as set before the stimulus. So this is the first thing a reviewer would object to, and it weakens the interpretability that is the reason to switch. The LNR has no parameter of that kind (its threshold is fixed). Discriminability is also the quantity whose meaning changes most with the switch: participants’ estimates agree only moderately between the models (ρ = 0.47).

Next step. Refit the DDM-5 with the boundary and the start point depending on Group and illusion only, not on strength or difficulty, and repeat this comparison on it. The illusions are blocked, so a boundary per illusion is legitimate. If the caution and illusion-magnitude results hold there, the DDM is the clearer model for the paper.
